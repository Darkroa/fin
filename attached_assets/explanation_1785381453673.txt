AllMart — VPS Deployment & Cloudflare Domain Guide
=====================================================

This guide covers deploying AllMart on a fresh VPS (Ubuntu 22.04/24.04)
and connecting it to a custom domain via Cloudflare.

Follow the steps in order — security hardening comes first, before
installing anything else.


═══════════════════════════════════════════════════════════════
PART 1 — SERVER PREPARATION & SECURITY HARDENING
═══════════════════════════════════════════════════════════════

Step 1: Create a VPS
─────────────────────
  • Any provider works (Hetzner, DigitalOcean, Vultr, Linode, etc.)
  • Recommended minimum: 1 vCPU, 2 GB RAM, 20 GB SSD
  • OS: Ubuntu 22.04 LTS or 24.04 LTS
  • Open ports in your provider's firewall: 22 (SSH), 80 (HTTP), 443 (HTTPS)

Step 2: SSH into the server (as root)
───────────────────────────────────────
  ssh root@YOUR_SERVER_IP

  ⚠ You are now root. Complete Steps 3–8 before installing anything.

Step 3: Create a non-root user
────────────────────────────────
Running everything as root is dangerous. Create a regular user instead.

  adduser allmart
  # enter a strong password when prompted

  usermod -aG sudo allmart
  # gives the user sudo access when needed

Step 4: Set up SSH key login (disable password login)
───────────────────────────────────────────────────────
On YOUR local machine (not the server), generate a key pair if you
don't have one:

  ssh-keygen -t ed25519 -C "supportallmart@gmail.com"
  # press Enter to accept defaults

Copy your public key to the server:
  ssh-copy-id allmart@YOUR_SERVER_IP
  # enter the user password one last time

Test that key login works — open a NEW terminal and run:
  ssh allmart@YOUR_SERVER_IP
  # should log in without asking for a password

Now disable password and root authentication on the server:
  sudo nano /etc/ssh/sshd_config

  Find and set these lines (add them if missing):
    PermitRootLogin no
    PasswordAuthentication no
    PubkeyAuthentication yes

  Save the file, then restart SSH:
    sudo systemctl restart sshd

  IMPORTANT: keep your current session open while testing in a second
  terminal — if you lock yourself out you can fix it from the open session.

From now on, log in as:
  ssh allmart@YOUR_SERVER_IP

Step 5: Configure the firewall (UFW)
──────────────────────────────────────
Only allow the ports AllMart actually needs.

  sudo apt-get install -y ufw

  sudo ufw default deny incoming
  sudo ufw default allow outgoing

  sudo ufw allow 22/tcp      # SSH
  sudo ufw allow 80/tcp      # HTTP  (Nginx + Cloudflare)
  sudo ufw allow 443/tcp     # HTTPS (Nginx + Cloudflare)

  sudo ufw enable            # type "y" to confirm
  sudo ufw status            # verify the rules

NOTE: do NOT open port 8080. Nginx proxies traffic to it internally —
it should never be exposed directly to the internet.

Step 6: Enable automatic security updates
───────────────────────────────────────────
Keep the OS patched automatically without manual intervention.

  sudo apt-get install -y unattended-upgrades
  sudo dpkg-reconfigure --priority=low unattended-upgrades
  # select "Yes" when prompted

  sudo systemctl status unattended-upgrades   # verify it is active

Step 7: Install Fail2Ban (block brute-force attacks)
──────────────────────────────────────────────────────
Fail2Ban watches logs and bans IPs that repeatedly fail SSH login.

  sudo apt-get install -y fail2ban

  sudo nano /etc/fail2ban/jail.local

  Paste this:

    [sshd]
    enabled   = true
    port      = 22
    maxretry  = 5
    bantime   = 1h
    findtime  = 10m

  Save, then start the service:
    sudo systemctl enable --now fail2ban
    sudo fail2ban-client status sshd    # verify it is watching SSH

Step 8: Secure shared memory
──────────────────────────────
Prevents a class of privilege-escalation attacks.

  sudo nano /etc/fstab

  Add this line at the bottom:
    tmpfs /run/shm tmpfs defaults,noexec,nosuid 0 0

  Apply without rebooting:
    sudo mount -o remount /run/shm

Step 9: Install Node.js 24
────────────────────────────
  curl -fsSL https://deb.nodesource.com/setup_24.x | bash -
  sudo apt-get install -y nodejs

  Verify:
    node -v   # should print v24.x.x

Step 10: Install pnpm
──────────────────────
  sudo npm install -g pnpm
  pnpm -v   # should print 9.x or later

Step 11: Install PostgreSQL
────────────────────────────
  Option A — Use Supabase (recommended, no server config needed):
    Create a free project at https://supabase.com
    Copy the "Connection string" (URI format) from Project Settings → Database
    Use it as SUPABASE_DB_URL / DATABASE_URL in your .env

  Option B — Install PostgreSQL locally:
    sudo apt-get install -y postgresql postgresql-contrib
    sudo systemctl enable --now postgresql
    sudo -u postgres psql -c "CREATE DATABASE allmart;"
    sudo -u postgres psql -c "CREATE USER allmart WITH PASSWORD 'strongpassword';"
    sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE allmart TO allmart;"
    # Connection string: postgres://allmart:strongpassword@localhost:5432/allmart

Step 12: Install git
─────────────────────
  sudo apt-get install -y git


═══════════════════════════════════════════════════════════════
PART 2 — DEPLOY THE APPLICATION
═══════════════════════════════════════════════════════════════

Step 13: Clone the repository
───────────────────────────────
  cd /opt
  sudo git clone https://github.com/YOUR_ORG/allmart.git
  sudo chown -R allmart:allmart /opt/allmart
  cd /opt/allmart

Step 14: Create the environment file
──────────────────────────────────────
  cp .env.example .env
  nano .env               # edit with your values

  Required variables:
    DATABASE_URL=postgres://allmart:strongpassword@localhost:5432/allmart
    # (or your Supabase connection string)
    SUPABASE_DB_URL=postgres://...   # same as DATABASE_URL if using Supabase
    SESSION_SECRET=<random 32+ char string>
    PORT_API=8080
    NODE_ENV=production
    APP_URL=https://yourdomain.com

  Generate a SESSION_SECRET:
    node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

  Optional — S3-compatible file storage (images):
    FILE_ENDPOINT_URL=https://...
    FILE_BUCKET=your-bucket-name
    FILE_ACCESS_KEY_ID=your-key
    FILE_SECRET_ACCESS_KEY=your-secret
    FILE_REGION=auto

  Optional — AI features:
    GROQ_API_KEY=gsk_...
    NVIDIA_API_KEY=nvapi-...

  Optional — Email (SMTP or Resend):
    SMTP_HOST=smtp.example.com
    SMTP_PORT=587
    SMTP_USER=user@example.com
    SMTP_PASSWORD=yourpassword

  Optional — Telegram bot:
    TELEGRAM_BOT_TOKEN=7123456789:AAF...
    TELEGRAM_CHAT_ID=-100123456789
    TELEGRAM_WEBHOOK_SECRET=any-random-string

  Optional — Payments:
    STRIPE_SECRET_KEY=sk_live_...
    STRIPE_WEBHOOK_SECRET=whsec_...

Step 15: Protect the .env file
────────────────────────────────
The .env file contains your database password, session secret, and API keys.
Lock it down immediately after creating it.

  chmod 600 /opt/allmart/.env
  chown allmart:allmart /opt/allmart/.env

  Only the allmart user (and root) can now read it.

Step 16: Install dependencies
───────────────────────────────
  pnpm install

Step 17: Push the database schema
───────────────────────────────────
  pnpm --filter @workspace/db run push

  This applies all tables and columns without destroying existing data.

Step 18: Seed the admin user
──────────────────────────────
  pnpm --filter @workspace/db run seed

  Note the printed admin credentials — change the password after first login.

Step 19: Build the application
────────────────────────────────
  bash deploy.sh

  This runs install + build + db push + seed in one step.
  Or build manually:
    pnpm --filter @workspace/api-server run build
    pnpm --filter @workspace/storefront run build

Step 20: Test the server manually
───────────────────────────────────
  bash start.sh

  Visit http://YOUR_SERVER_IP:8080 in a browser to confirm it works.
  Press Ctrl+C to stop after confirming.

Step 21: Set up a systemd service (keeps the app running)
───────────────────────────────────────────────────────────
  Create the service file:
    sudo nano /etc/systemd/system/allmart.service

  Paste this:

    [Unit]
    Description=AllMart
    After=network.target

    [Service]
    Type=simple
    User=allmart
    WorkingDirectory=/opt/allmart
    EnvironmentFile=/opt/allmart/.env
    ExecStart=/bin/bash /opt/allmart/start.sh
    Restart=on-failure
    RestartSec=10

    [Install]
    WantedBy=multi-user.target

  Enable and start:
    sudo systemctl daemon-reload
    sudo systemctl enable allmart
    sudo systemctl start allmart
    sudo systemctl status allmart    # should show "active (running)"

  View logs:
    journalctl -u allmart -f

PART 3 — INSTALL NGINX AS REVERSE PROXY
═══════════════════════════════════════════════════════════════

AllMart's API server runs on port 8080. Nginx sits in front on port
80/443, forwards requests to it, and handles SSL termination.

Step 22: Install Nginx
────────────────────────
  sudo apt-get install -y nginx
  sudo systemctl enable --now nginx

Step 23: Create an Nginx site config
──────────────────────────────────────
  sudo nano /etc/nginx/sites-available/allmart

  Paste:

    server {
        listen 80;
        server_name yourdomain.com www.yourdomain.com;

        client_max_body_size 50M;

        location / {
            proxy_pass         http://127.0.0.1:8080;
            proxy_http_version 1.1;
            proxy_set_header   Upgrade $http_upgrade;
            proxy_set_header   Connection 'upgrade';
            proxy_set_header   Host $host;
            proxy_set_header   X-Real-IP $remote_addr;
            proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header   X-Forwarded-Proto $scheme;
            proxy_cache_bypass $http_upgrade;
        }
    }

  Replace `yourdomain.com` with your actual domain.

  Enable the site:
    sudo ln -s /etc/nginx/sites-available/allmart /etc/nginx/sites-enabled/
    sudo nginx -t                   # test config — must say "ok"
    sudo systemctl reload nginx

Step 24: Harden Nginx
───────────────────────
Add security headers inside the http { } block in /etc/nginx/nginx.conf:

  sudo nano /etc/nginx/nginx.conf

  Add inside http { } (before the include lines at the bottom):

    # Hide Nginx version from error pages and headers
    server_tokens off;

    # Prevent clickjacking
    add_header X-Frame-Options SAMEORIGIN;

    # Prevent MIME-type sniffing
    add_header X-Content-Type-Options nosniff;

    # Enable XSS filter in older browsers
    add_header X-XSS-Protection "1; mode=block";

    # Only send referrer on same origin
    add_header Referrer-Policy "strict-origin-when-cross-origin";

    # Limit request body size (matches AllMart's file upload limit)
    client_max_body_size 50M;

  Test and reload:
    sudo nginx -t && sudo systemctl reload nginx


═══════════════════════════════════════════════════════════════
PART 4 — CLOUDFLARE DOMAIN SETUP
═══════════════════════════════════════════════════════════════

Step 25: Add your domain to Cloudflare
────────────────────────────────────────
  1. Sign up or log in at https://cloudflare.com
  2. Click "Add a Site" and enter your domain name.
  3. Choose the Free plan (sufficient for most use).
  4. Cloudflare will scan your existing DNS records.

Step 26: Update nameservers at your registrar
───────────────────────────────────────────────
  Cloudflare will show you two nameserver addresses, e.g.:
    aria.ns.cloudflare.com
    bob.ns.cloudflare.com

  Go to your domain registrar (Namecheap, GoDaddy, Google Domains, etc.)
  and replace the current nameservers with the Cloudflare ones.

  Propagation typically takes 5–30 minutes (up to 48h in rare cases).

Step 27: Add DNS records in Cloudflare
────────────────────────────────────────
  In the Cloudflare dashboard → DNS → Records, add:

    Type   Name    Content              Proxy status
    ────   ──────  ───────────────────  ────────────
    A      @       YOUR_SERVER_IP       Proxied (orange cloud)
    A      www     YOUR_SERVER_IP       Proxied (orange cloud)

  "Proxied" means traffic routes through Cloudflare (CDN + DDoS protection).

Step 28: Set SSL/TLS mode in Cloudflare
─────────────────────────────────────────
  Cloudflare → SSL/TLS → Overview → set mode to "Full (strict)"

  This requires a real certificate on your server (done in the next step).
  If you skip the cert step, use "Full" (not strict) temporarily.

Step 29: Install a free SSL certificate (Let's Encrypt)
─────────────────────────────────────────────────────────
  sudo apt-get install -y certbot python3-certbot-nginx

  Obtain a certificate:
    sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

  Follow the prompts (enter email, agree to terms).
  Certbot will automatically update your Nginx config for HTTPS.

  Auto-renewal is set up automatically. Test it with:
    sudo certbot renew --dry-run

Step 30: Reload Nginx
──────────────────────
  sudo nginx -t && sudo systemctl reload nginx

  Your site should now be live at https://yourdomain.com


═══════════════════════════════════════════════════════════════
PART 5 — POST-DEPLOYMENT TASKS
═══════════════════════════════════════════════════════════════

Step 31: Verify open ports
────────────────────────────
Confirm only expected ports are exposed before going live.

  sudo ss -tlnp

  You should see ONLY:
    *:22    — SSH (sshd)
    *:80    — HTTP (nginx)
    *:443   — HTTPS (nginx)
    127.0.0.1:8080 — AllMart API (local only, not exposed)

  If port 8080 shows 0.0.0.0:8080 (all interfaces), something is wrong —
  check your UFW rules and AllMart's PORT_API binding.

Step 32: Register the Telegram webhook (if using Telegram bot)
───────────────────────────────────────────────────────────────
  1. Ensure TELEGRAM_BOT_TOKEN and TELEGRAM_WEBHOOK_SECRET are set in .env
  2. Log in to AllMart admin panel → Telegram Bot → "Register webhook"
  3. The webhook URL will be: https://yourdomain.com/api/telegram/webhook

Step 33: Configure Stripe webhook (if using payments)
───────────────────────────────────────────────────────
  1. Go to https://dashboard.stripe.com/webhooks
  2. Add endpoint: https://yourdomain.com/api/stripe/webhook
  3. Select events: payment_intent.succeeded, checkout.session.completed
  4. Copy the signing secret → add as STRIPE_WEBHOOK_SECRET in .env
  5. Restart the service: sudo systemctl restart allmart

Step 34: Set up hourly database backups
──────────────────────────────────────────
  crontab -e

  Add this line:
    0 * * * * cd /opt/allmart && pnpm --filter @workspace/scripts run backup >> /tmp/backup.log 2>&1

  Verify:
    tail -f /tmp/backup.log

PART 7 — CLOUDFLARE PERFORMANCE TIPS (optional)
═══════════════════════════════════════════════════════════════

• Speed → Optimization → enable "Auto Minify" (HTML, CSS, JS)
• Caching → Configuration → set "Browser Cache TTL" to 1 day
• Speed → Optimization → enable "Rocket Loader" (may conflict with some JS)
• Security → Settings → set "Security Level" to Medium
• Rules → Page Rules → cache static assets:
    Pattern: yourdomain.com/assets/*
    Setting: Cache Level = Cache Everything, Edge TTL = 1 month

PART 8 — AUTO-DEPLOY ON PUSH (GitHub Actions)
═══════════════════════════════════════════════════════════════

Every time you push to the main branch, GitHub Actions will SSH into
your VPS, pull the latest code, rebuild, and restart — fully automated.


────────────────────────────────────────────────────────────────
STEP A — Add your VPS SSH key to GitHub Secrets
────────────────────────────────────────────────────────────────
On your VPS, generate a dedicated deploy key:

  ssh-keygen -t ed25519 -C "github-deploy" -f ~/.ssh/deploy_key -N ""

Add the PUBLIC key to authorized_keys so GitHub can SSH in:

  cat ~/.ssh/deploy_key.pub >> ~/.ssh/authorized_keys

Copy the PRIVATE key — you'll paste it into GitHub:

  cat ~/.ssh/deploy_key

In your GitHub repo → Settings → Secrets and variables → Actions → New secret:

  Name: VPS_SSH_KEY
  Value: (paste the entire private key including -----BEGIN and -----END lines)

Add two more secrets:

  Name: VPS_HOST
  Value: your.server.ip.address   (or domain, e.g. yourdomain.com)

  Name: VPS_USER
  Value: allmart


────────────────────────────────────────────────────────────────
STEP B — Allow the allmart user to restart the service without a password
────────────────────────────────────────────────────────────────
  sudo visudo

  Add this line at the bottom:
    allmart ALL=(ALL) NOPASSWD: /bin/systemctl restart allmart, /bin/systemctl is-active allmart

  Save and exit (Ctrl+X, Y in nano; :wq in vim).


────────────────────────────────────────────────────────────────
STEP C — Create the workflow file
────────────────────────────────────────────────────────────────
In your repo, create the file .github/workflows/deploy.yml and paste:

─────────────────────────── deploy.yml ────────────────────────
name: Deploy to VPS

on:
  push:
    branches:
      - main

jobs:
  deploy:
    name: Pull & restart on VPS
    runs-on: ubuntu-latest
    timeout-minutes: 15

    steps:
      - name: Deploy via SSH
        uses: appleboy/ssh-action@v1.0.3
        with:
          host:        ${{ secrets.VPS_HOST }}
          username:    ${{ secrets.VPS_USER }}
          key:         ${{ secrets.VPS_SSH_KEY }}
          script_stop: true
          script: |
            set -euo pipefail
            cd /opt/allmart
            git pull origin main
            bash deploy.sh
            sudo systemctl restart allmart
            sleep 5
            curl -fsS http://localhost:8080/api/healthz \
              || { echo "Health check failed"; sudo systemctl stop allmart; exit 1; }
            echo "Deploy complete ✓"

      - name: Notify Telegram (success)
        if: success()
        run: |
          curl -s -X POST "https://api.telegram.org/bot${{ secrets.TELEGRAM_BOT_TOKEN }}/sendMessage" \
            -d chat_id="${{ secrets.TELEGRAM_CHAT_ID }}" \
            -d text="✅ AllMart deployed — ${{ github.ref_name }} @ ${{ github.sha }}"

      - name: Notify Telegram (failure)
        if: failure()
        run: |
          curl -s -X POST "https://api.telegram.org/bot${{ secrets.TELEGRAM_BOT_TOKEN }}/sendMessage" \
            -d chat_id="${{ secrets.TELEGRAM_CHAT_ID }}" \
            -d text="❌ AllMart deploy FAILED — ${{ github.ref_name }} — check Actions tab."
────────────────────────────────────────────────────────────────


────────────────────────────────────────────────────────────────
STEP D — Push to trigger the first deploy
────────────────────────────────────────────────────────────────
  git add .github/workflows/deploy.yml
  git commit -m "Add auto-deploy workflow"
  git push origin main

  Go to your repo → Actions tab to watch the run.
  Green tick = deployed. Red cross = click the job to see what failed.
